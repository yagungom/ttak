# 딱! 홈런 ⚾

**한 손**으로 던지고 **한 손**으로 치는 가족 야구 게임. 수비는 없고, **날아간 거리(m)가 그대로 점수**예요.
설치 없이 **크롬(웹/모바일 웹)** 에서 돌아가고, 폰을 **TV에 미러링**해서 큰 화면으로 즐기는 걸 기본으로 만들었습니다.

- 빌드 도구 없음: 정적 파일 그대로 배포 (HTML + JS 모듈)
- 사람 인식: MediaPipe 자세 인식 (기기 안에서 처리, 영상 전송 없음) — 엔진·모델을 이 폴더에 같이 넣어 외부 서버 호출 없음
- 플레이 방식 2종: 📺 **카메라 모드**(둘이 몸으로, TV 미러링 추천) / 📱 **폰 모드**(손가락, 혼자면 🤖 컴퓨터와)
- 화면은 포수 자리에서 본 야구장. 친 공은 카메라가 따라가며 거리를 보여 줘요

---

## 1. 배포 (Vercel, 약 5분)

카메라는 **https 주소에서만** 켜지므로 배포가 필요합니다.

1. 이 폴더를 GitHub 저장소에 올립니다.
2. [vercel.com](https://vercel.com) → **Add New → Project** → 저장소 선택 → Framework: **Other** → Deploy
   - Build Command·Output 설정 필요 없음 (정적 사이트)
3. 받은 `https://xxx.vercel.app` 주소를 갤럭시 크롬으로 열면 끝.
4. 크롬 메뉴 → **홈 화면에 추가** 하면 주소창 없는 전체화면 앱처럼 실행됩니다.

> Netlify·Cloudflare Pages도 됩니다 (`_headers` 파일이 보안 헤더를 적용).

**PC에서 먼저 확인:** 폴더에서 `npx serve .` → `http://localhost:3000` (localhost는 https 아니어도 카메라 허용).

## 2. 📺 카메라 모드 (둘이)

| 할 일 | 방법 |
|---|---|
| 폰 세우기 | 폰을 **가로**로 세워 두 사람 쪽을 보게 두고, TV에 미러링. 두 사람이 **나란히 2~3걸음 뒤**에 서기 |
| 자리 | 화면 가운데 점선 기준 **왼쪽 반에 한 명, 오른쪽 반에 한 명** (왼쪽 선수가 먼저 공격) |
| 손 정하기 | 대기실에서 자기 앞 공을 **톡 친 손**이 그 사람의 손. 다른 손은 아예 안 봐요 |
| 던지기 (🧢 투수) | 그 손을 **머리(어깨) 위로 들었다가 → 앞·아래로 빠르게 내리면** 던짐 (작은 창의 손 점이 초록색 = 준비 OK). 빠를수록 빠른 공(km/h 표시). 내리는 **방향**(왼쪽·오른쪽) + 손이 **멈춘 높이**(가슴 = 높은 공, 배꼽 = 가운데, 끝까지 = 낮은 공) = 공이 들어오는 곳. 옆으로 흔들거나 위로 올리는 동작은 무시. 공은 언제나 스트라이크존 안 |
| 치기 (⚾ 타자) | 손을 **몸 바깥쪽**(어깨 옆)에 두고 있다가 → 공이 홈에 올 때 **몸 앞을 가로질러 안쪽으로 빠르게** = 스윙. 안쪽에서 바깥으로 빼는 동작은 무시. 세게 휘두를수록 멀리. 일찍 치면 왼쪽(당겨치기), 늦으면 오른쪽(밀어치기). 어른은 손 높이도 맞춰야 멀리 감 (배트가 공보다 낮으면 뜬공, 높으면 땅볼) |
| 화면 | 위쪽 양 구석에 각자 카메라 작은 창 (노란 점 = 인식된 손). 지금 할 사람 창이 노랗게 깜빡여요 |
| 배려 | 한 사람이라도 2초간 안 보이면 자동 멈춤 → 다시 서면 이어서 (날아오던 공은 다시 던짐) |

- 시작 화면에서 **📷 후면 / 🤳 전면** 카메라를 고르고, 대기실의 **카메라 바꾸기**를 누를 때마다 다음 렌즈로 바뀝니다 (선택은 저장됨)
- 게임 화면은 항상 **16:9** 로 그려서 TV에 꽉 찹니다
- 끝나면 각자 자기 앞 공을 다시 톡 → 한 판 더 (폰 안 만지고 계속 가능)

## 3. 📱 폰 모드 (손가락)

| 상황 | 조작 |
|---|---|
| 혼자 + 🤖 컴퓨터 | 화면 어디든 내 것. 던질 땐 **스트라이크존의 던질 곳을 누르고 휙 쓸기**, 칠 땐 **공 높이를 톡** |
| 두 사람 | 화면 **왼쪽 반 = 왼쪽 선수, 오른쪽 반 = 오른쪽 선수**. 투수는 자기 쪽 **던질 곳 판**을 누르고 휙, 타자는 자기 쪽 아무 데나 톡 |
| 세기 | 던지기: 빨리 쓸수록 빠른 공 / 치기: 톡 = 보통, **옆으로 휙 쓸면 더 세게** |

- 폰 모드는 폰 화면을 꽉 채워요 (가로·세로·폴드 모두)
- PC에서는 마우스로 해 볼 수 있어요 (`?touch`)

## 4. 게임 규칙

| 항목 | 내용 |
|---|---|
| 점수 | 수비 없음. 친 공은 무조건 페어 지역 안으로 날아가고, **처음 떨어진 곳까지의 거리(m)** 가 그대로 점수 |
| 아웃 | **헛스윙 + 안 친 공(포수가 받은 공) 합쳐서 3개 = 아웃**. 안타를 쳐도 스트라이크는 그대로라서, 스트라이크 3개가 될 때까지 계속 쳐서 거리를 모아요 |
| 공수교대 | 3아웃이면 교대. 초 = 왼쪽 선수 공격, 말 = 오른쪽 선수 공격 |
| 승부 | **1·2·3회** 중 고른 회까지 끝까지 하고(끝내기 없음), 거리 합계가 많은 쪽이 승리 |
| 홈런 | 담장(파울라인 쪽 92m, 가운데 112m)을 넘기면 홈런! (점수는 똑같이 거리) |
| 투수가 안 던지면 | 9초 뒤 안내, 16초 지나면 자동으로 살살 던짐 |
| 선수 종류 | 🧑 **어른**: 빠른 공, 타이밍·높이 둘 다 중요 · 🧒 **어린이**: 공이 느리게 오고 맞는 범위가 넓음, 높이는 거의 상관없음, 공이 올 곳에 **타이밍 동그라미**(작아질 때 '지금!'). 던질 때도 약하게·대충 던져도 가운데로 · 🤖 **컴퓨터**: 폰 모드 혼자 할 때 상대, 가끔 헛스윙·지켜봄 |
| 공 속도 | 구속(km/h)은 던진 사람 기준, 실제로 날아오는 시간은 치는 사람 기준 (같은 140km/h도 아이에겐 느리게) |
| 맞히는 난이도 | 빠른 공일수록 맞는 타이밍 범위가 좁아요 → 투수도 세게 던질 이유가 있음 |
| 타격감 | 맞는 순간 멈칫 + 화면 흔들림 + 번쩍임·불꽃 + '딱!' 소리. 잘 맞을수록 크게. 타이밍이 빨랐는지 늦었는지 화면에 알려 줌 |

숫자(구속·날아오는 시간·맞는 범위·비거리·담장 거리·안타 뒤 카운트 초기화 여부 `RESET_ON_HIT` 등)는 `js/config.js` 에서 바꿀 수 있어요.

## 5. 사람 인식 방식 (카메라 모드)

- 카메라 프레임을 좌우 반쪽으로 잘라 **자세 인식(Pose Landmarker)을 두 개** 따로 돌림 → 한쪽에 두 명이 있어도 선수는 그 반쪽에서 한 명만 (통통 테니스와 같은 방식)
- 사람마다 **정한 한 손만** 보고, 그 손의 속도를 **어깨 폭 기준**으로 재서 아이·어른, 가까이·멀리 서도 비슷하게 판정
- 던지기: 최근 1.2초 안에 손이 어깨선 위에 있었고(어린이는 1.6초·어깨선까지), 어깨 근처보다 위에서 시작해 **아래쪽이 주된 방향**으로 빠르게 움직일 때만. 팔이 멈추는(다시 올라가는) 순간까지 따라가서 멈춘 높이로 공 높이를 정함
- 치기: 손이 몸 가운데에서 어깨 폭의 35%(어린이 25%) 넘게 바깥에 있다가, **옆이 주된 방향으로 몸 가운데 쪽으로** 빠르게 움직일 때만. 공이 날아오는 동안의 첫 스윙 한 번만 판정. 카메라·인식이 늦는 시간과 TV가 늦게 보이는 시간만큼 판정을 늦춰 줌 (**설정 → 타이밍 보정**: 무선 미러링이 많이 늦으면 '크게')
- 인식은 별도 처리(Web Worker)에서 돌려 게임 화면은 부드럽게. 그래픽 가속(GPU)이 10초간 응답이 없으면 자동으로 CPU로 전환
- 손이 순간 튀는 인식 오류(사람 손으로 불가능한 속도)는 판정에서 제외

## 6. 🏆 랭킹

와르르 캐치·뻥! 승부차기와 **같은 Supabase 프로젝트, 같은 방식**(로그인 없이 팀 이름, 서버 함수 3개, 1회용 세션, IP 해시 2일 보관)입니다.

| 항목 | 내용 |
|---|---|
| 이름 | 시작 화면의 **팀 이름**(2~12자, 비우면 '우리 가족') + 선수 이름(1~6자). 숫자 7자리 이상·욕설 금지 |
| 기록 | 경기가 끝나면 **사람 선수마다** 1개 (둘이 하면 2개, 컴퓨터는 안 올림) |
| 순위 두 가지 | 🏏 **비거리** = 한 경기에서 가장 멀리 친 공 / 📏 **총 비거리** = 한 경기 합계 (1·2·3회 경기는 따로) |
| 나누는 기준 | 🧑 어른 / 🧒 어린이 × 📺 카메라 / 📱 폰 × 오늘 / 이번 주 / 이번 달 (한국시간) |
| 화면 | 상위 몇 %, 거리 분포 그래프, TOP 10. 🌐 전체 / 🏠 우리 기기 |
| 부정 방지 | 서버가 경기 시작 때 세션을 주고, 끝날 때 **친 공 거리 목록**을 받아 합계·최고·홈런 수를 다시 계산. 한 방 145m 넘음·너무 빨리 끝난 경기는 거절 |
| 개인정보 | 올라가는 것: 팀 이름, 선수 이름, 선수 종류, 방식, 회 수, 친 공 거리들. 도배 방지용 IP는 알아볼 수 없게(날짜별 솔트 해시) 2일만. 로그인·이메일·연락처 없음 |

**처음 한 번:** Supabase 대시보드 → SQL Editor → `supabase/schema.sql` 전체 붙여넣기 → Run. (다른 두 게임 기록은 건드리지 않고 `hr_` 로 시작하는 표·함수만 더해요. 공용 부품은 세 게임이 똑같은 내용.) 실행 전에는 게임이 '이 기기 기록'만 보여 줘요.

## 11. 알아두면 좋은 점
