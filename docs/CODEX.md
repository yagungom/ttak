# Codex 작업 지시 — 딱! 홈런 그림 7장

VS Code의 Codex에게 이 파일을 읽고 그대로 하라고 하면 됩니다.

## 할 일

`docs/PROMPTS.md` 에 있는 그림 7장을 **Codex 자체 이미지 생성 기능**(ChatGPT 구독, API 키 없이)으로 그려서, 적힌 경로에 저장하고 GitHub에 올린다.

## 순서

1. 저장소 준비
   - 이 폴더가 `yagungom/ttak` 저장소인지 확인하고 `git pull` (없으면 `git clone https://github.com/yagungom/ttak`)
   - git 설정 (이 저장소에만): `git config user.name "yagungom"` / `git config user.email "165270616+yagungom@users.noreply.github.com"`
   - **회사 이메일로 커밋하지 말 것**
2. `docs/PROMPTS.md` 를 끝까지 읽는다. 특히 "게임이 그림을 쓰는 방식" 규칙.
3. 1번(어른 투수)부터 7번까지 **순서대로** 그린다.
   - 각 항목의 프롬프트 블록을 그대로 쓴다. 2번부터는 "1번과 같은 그림체"를 맞추려고 앞에서 만든 그림을 참고 이미지로 함께 넣어도 좋다.
   - 크기: 1~4번 1536×1024 가로, 5~7번 1024×1024
4. 한 장 만들 때마다 직접 열어 보고 확인한다. 하나라도 틀리면 다시 그린다 (한 그림당 최대 3번).
   - [ ] 1~4번: 칸이 정확히 가로 3 × 세로 2, 동작 순서가 맞음
   - [ ] 1~4번: 캐릭터·팔·배트가 칸 밖으로 안 나가고 옆 칸과 안 닿음, 6칸 모두 발끝 높이가 같음
   - [ ] 1~4번: 6칸이 같은 캐릭터, 파란색은 유니폼 상의·모자/헬멧에만
   - [ ] 투수는 정면·던지는 손이 그림 오른쪽, 타자는 뒷모습·배트가 그림 오른쪽으로 휘둘러짐
   - [ ] 배경: 투명 또는 깨끗한 흰색 단색 (5번 관중석만 꽉 찬 그림)
   - [ ] 글자·숫자·로고·워터마크 없음, 실제 팀·캐릭터와 안 닮음, 적십자(흰 바탕 빨간 십자) 없음
5. 확인이 끝난 그림은 **PNG로** `docs/PROMPTS.md` 에 적힌 경로·이름 그대로 저장하고, 한 장마다 바로 커밋·push
   - 커밋 메시지: `그림: assets/players/pitcher.png` 처럼 파일 경로
   - `git push origin main`
6. 7장 모두 끝나면 결과를 알려 준다: 만든 파일 목록, 그림마다 다시 그린 횟수, 마음에 안 드는 점이 남은 그림.

## 하지 말 것

- 코드(`js/`, `css/`, `index.html`), `docs/PROMPTS.md`, 이 파일은 고치지 않는다. **그림 파일만 추가**
- 그림을 webp로 바꾸거나 자르거나 줄이지 않는다 (나중에 Claude가 정리)
- ChatGPT 웹 채팅창을 자동으로 조작하지 않는다 (OpenAI 약관 위반). Codex 자체 이미지 생성만 사용
- 이미 올라간 그림을 강제 푸시로 덮어쓰지 않는다. 다시 그리면 새 커밋으로 올린다
